СЕВЕРНАЯ ЗВЕЗДА — V5.1
=======================

Что исправлено:
- защита формы записи от спама: серверный rate-limit по хэшированному IP и телефону, honeypot, ограничение размера запроса, защита от cross-site POST;
- защита от случайного двойного клика/повтора запроса: request_id и идемпотентность;
- rate-limit входа в админку;
- RLS для рабочих таблиц Supabase;
- исправлена читаемость тёмной темы;
- новая запись автоматически сохраняется в браузере клиента;
- на главной появляется кнопка «Мои записи»;
- booking.html умеет открыть сохранённые записи даже без ссылки в адресной строке;
- при изменении даты/времени администратором клиент видит крупное предупреждение «Клиника изменила запись»;
- страница записи автоматически обновляется каждые 30 секунд, пока открыта;
- отзывы после отправки сохраняются в БД, попадают в админку и отправляют Push администратору;
- отзывы в админке загружаются независимо от настроек услуг: сбой одного раздела больше не скрывает другой;
- неопубликованные отзывы отображаются в центре уведомлений админки;
- отзывы на главной сделаны компактной горизонтальной лентой;
- надпись про первую субботу убрана из верхних мини-плашек и оставлена в отдельном блоке травматолога;
- добавлены базовые security headers Netlify.

УСТАНОВКА
---------
1. СНАЧАЛА открой Supabase -> SQL Editor -> New query.
2. Вставь целиком содержимое файла:
   supabase/v5.1-security-comfort.sql
3. Нажми Run и дождись Success.
4. Затем загрузи СОДЕРЖИМОЕ этой папки в корень GitHub с заменой файлов.
5. Дождись Published в Netlify.
6. После деплоя проверь:
   - обычную запись;
   - кнопку «Мои записи»;
   - изменение времени из админки;
   - отправку отзыва после завершённой записи;
   - раздел «Отзывы» и «Центр уведомлений» в админке;
   - светлую и тёмную тему.

ВАЖНО
-----
Новых обязательных переменных окружения нет.
Защита rate-limit использует ADMIN_SESSION_SECRET как соль для HMAC.
При желании позже можно добавить отдельную RATE_LIMIT_SECRET, но это не обязательно.

Текущие переменные Netlify должны остаться:
SUPABASE_URL
SUPABASE_SECRET_KEY
VAPID_PUBLIC_KEY
VAPID_PRIVATE_KEY
ADMIN_LOGIN
ADMIN_PASSWORD
ADMIN_SESSION_SECRET

Опционально:
VAPID_SUBJECT
RATE_LIMIT_SECRET
