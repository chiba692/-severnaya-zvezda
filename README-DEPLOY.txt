СЕВЕРНАЯ ЗВЕЗДА — SECURITY HARDENED v4

ВАЖНО: текущий live-сайт старее этой сборки. Этот ZIP включает последние удобства админки, полный прайс и security hardening.

ПОРЯДОК:
1. Заменить содержимое локального репозитория содержимым этого ZIP.
2. GitHub Desktop: Commit to main -> Push origin и дождаться Netlify Published.
3. Проверить, что главная и админка открываются. До миграции полный прайс может быть пустым — это ожидаемо.
4. В Supabase SQL Editor выполнить supabase/SECURITY-HARDENING-MIGRATION.sql один раз.
5. Обновить сайт и выполнить smoke/security проверку.

ПОЧЕМУ КОД СНАЧАЛА:
Hardened v4 специально умеет работать со старой production-схемой до миграции. Так старый клиентский код не увидит новые направления услуг раньше, чем backend научится их принимать.

NETLIFY ENV:
Обязательные существующие: SUPABASE_URL, SUPABASE_SECRET_KEY, ADMIN_LOGIN, ADMIN_PASSWORD, ADMIN_SESSION_SECRET, VAPID_PRIVATE_KEY.
VAPID public: код поддерживает и VAPID_PUBLIC_KEY, и старую опечатку VAPID_PUBLICK_KEY.
Рекомендуется позже добавить отдельный RATE_LIMIT_SECRET (случайная строка 32+ байта). Без него работает безопасный fallback на ADMIN_SESSION_SECRET.

ПРОВЕРКА:
npm run validate


CLIENT UX v5
- Исправлена невидимая подпись «Записаться» в тёмной теме.
- Удалён искусственный список «Общие / Биохимия / Другое» для анализов.
- Конкретная услуга теперь подбирается из полного прайса для выбранного направления.
- На главной «Основные направления» и «Весь прайс» разделены вкладками, поэтому они не дублируются одновременно.
- Полный прайс открывается через поиск и понятные разделы, а не длинным списком из 139 строк.
- Большой раздел «Общие услуги» разбит на клиентские категории.
- SQL остаётся кумулятивным и идемпотентным: достаточно одного SECURITY-HARDENING-MIGRATION.sql.

BOOKING UX v6
- Убрано дублирование «направление + конкретная услуга» из формы.
- В форме один выбор «Услуга»: поиск и реальные позиции полного прайса.
- Основные карточки остаются на главной, полный прайс вынесен на отдельную удобную страницу.
- Кнопка «Записаться» у УЗИ/рентгена/анализов/вакцинации/хирургии/стоматологии сразу открывает отфильтрованный список реальных услуг.
- Полный прайс передаёт в запись точный item_key, поэтому клиенту не нужно повторно выбирать или печатать название.
- SQL-схема не менялась относительно v5; повторный SQL для этого UX-патча не нужен.
