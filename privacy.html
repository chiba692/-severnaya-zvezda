Обработка персональных данных

Эта страница кратко объясняет, зачем ветеринарная клиника «Северная звезда» получает данные из формы записи.

Какие данные используются

Имя владельца, номер телефона, сведения о питомце, выбранная услуга, дата и время записи, а также комментарий, который вы указали сами.

Для чего

Только для оформления и ведения записи, связи с владельцем по поводу визита и организации работы клиники.

Кто получает доступ

Данные используются клиникой и техническими сервисами, необходимыми для работы сайта и хранения записей. Публично эти данные не публикуются.

Личная ссылка на запись

После отправки создаётся приватная ссылка. Не публикуйте её открыто: тот, у кого есть ссылка, может увидеть статус и основные данные записи.

Как связаться

По вопросам, связанным с записью и данными, позвоните в клинику: +7 911 648-06-44.
