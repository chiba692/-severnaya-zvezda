СЕВЕРНАЯ ЗВЕЗДА — V5
=====================

Эта сборка ставится ПОВЕРХ текущей V4.
Текущие переменные Netlify (Supabase, VAPID, ADMIN_LOGIN/ADMIN_PASSWORD/ADMIN_SESSION_SECRET) менять не нужно.

УСТАНОВКА
---------
1. Supabase -> SQL Editor -> New query.
2. Открой файл supabase/v5.sql, скопируй его целиком, вставь в New query и нажми Run.
   Нормальный результат: Success. No rows returned.
3. Распакуй ZIP и загрузи СОДЕРЖИМОЕ папки severnaya-zvezda-v5 в корень GitHub-репозитория с заменой старых файлов.
4. Дождись в Netlify статуса Published.
5. Открой сайт и админку. Если на телефоне осталась старая PWA, полностью закрой её и открой снова; service worker V5 обновится автоматически.

ЧТО ДОБАВЛЕНО
-------------
Клиентская часть:
- новый практичный дизайн без фотографий;
- услуги, цены и подготовка к визиту;
- цены/описания можно менять из админки без GitHub;
- ближайшее свободное время на главной;
- автоматический блок травматолога на первую субботу месяца;
- запись открывается отдельным аккуратным окном, а главная больше не выглядит как анкета;
- после записи клиент получает номер и защищённую личную ссылку;
- booking.html показывает актуальный статус заявки;
- клиент может отменить или перенести обычную запись по личной ссылке;
- после завершённого приёма можно отправить отзыв;
- на главной показываются только одобренные администратором отзывы;
- FAQ, звонок и маршрут;
- мобильная нижняя панель «Позвонить / Записаться».

Админка:
- статусы: новая -> принята -> пришёл -> на приёме -> завершена;
- отдельный экран «Сейчас в клинике»;
- отдельный экран стационара;
- внутренние заметки, которые клиент не видит;
- карточки питомцев и история посещений;
- быстрый звонок и повторная запись;
- улучшенный календарь с просмотром конкретного дня;
- аналитика за текущий месяц;
- центр уведомлений, который не исчезает при смахивании Push;
- счётчик новых заявок / badge там, где Android это поддерживает;
- включение Push прямо из админки;
- модерация отзывов;
- редактор услуг, цен, описаний и подготовки на клиентском сайте;
- PWA V5 с PNG-иконками 192/512 и быстрыми ярлыками.

ВАЖНО
-----
Личная ссылка клиента содержит длинный случайный токен. Её не нужно публиковать или пересылать посторонним: тот, у кого есть ссылка, может увидеть эту конкретную заявку и, пока она активна, отменить/перенести её.

После установки лучше проверить 7 сценариев:
1) обычная запись;
2) перенос по личной ссылке;
3) отмена и повторная запись в освободившийся слот;
4) цепочка «Принять -> Пришёл -> Начать приём -> Завершить»;
5) стационар;
6) Push на телефоне мамы;
7) отзыв после завершённой записи и его публикация из админки.
